Configure and test SMS messaging for your Digital Frames Shop

⚙️ Setup Instructions

1
Create a Twilio Account

Go to Twilio Sign Up and create a free trial account.

2
Get Your Credentials

After signup, find these in your Twilio Console:

  • Account SID: Found on the console dashboard
  • Auth Token: Click to reveal on the dashboard
  • Phone Number: Get a free trial number from the console
3
Set Environment Variables

Before starting your backend, set these environment variables:

export TWILIO_ACCOUNT_SID="your_account_sid" export TWILIO_AUTH_TOKEN="your_auth_token" export TWILIO_PHONE_NUMBER="+1234567890" ./mvnw spring-boot:run
4
Verify Phone Numbers (Trial Account)

With a trial account, you must verify phone numbers before sending SMS to them.

Go to Verified Phone Numbers to add recipients.

💡 Troubleshooting

Common Issues:
  • SMS not sending: Check if Twilio credentials are set as environment variables
  • Phone number not verified: Trial accounts require phone verification
  • Invalid phone number: Ensure you include the country code
  • Service not initialized: Restart the backend after setting environment variables
